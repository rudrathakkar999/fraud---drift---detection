\# AIML-02: Fraud \& Anomaly Detection with Real-Time Drift Monitoring



An end-to-end fintech fraud detection system designed to combat silent model degradation. This repository implements cost-sensitive supervised learning, unsupervised anomaly detection, financial loss threshold optimization, and statistical covariate drift detection via the two-sample Kolmogorov-Smirnov test.
